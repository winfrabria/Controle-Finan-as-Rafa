# Gate humano do verificador 2026-08-25.1

O modo `enforce` permanece bloqueado até existir um corpus sanitizado de 50
anexos rotulados por humano, com expansão planejada para 100.

Critérios obrigatórios:

- recall crítico: 100%;
- recall geral: >= 95%;
- precisão: >= 90%;
- zero achado sem página/trecho/campo ou item afetado;
- zero segunda chamada do verificador para o mesmo fingerprint;
- nenhuma regressão de `READ_FAILED`, `INFORMATION_INSUFFICIENT`, perguntas
  públicas, capability, reprocessamento ou fluxo de leitura do Rafael.

O benchmark precisa registrar separadamente falsos positivos, falsos negativos,
limitações corretas, custo, tokens e latência. Resultado de modelo sem rótulo
humano não promove o gate.
