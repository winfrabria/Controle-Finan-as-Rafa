# Prompt de auditoria 2026-08-14.2

O prompt mantém a auditoria completa da versão anterior e acrescenta três
limites explícitos para a descoberta livre:

1. variação textual de nome só é achado com identificadores fiscais distintos;
2. associação de placa/equipamento só é achado com cadastro, regra ativa ou
   fonte oficial fornecida;
3. diferença de data só é achado quando os registros pertencem claramente à
   mesma transação e não existe explicação documental explícita.

O modelo continua retornando apenas JSON estruturado, sem raciocínio interno.
Observações informativas e limitações de cobertura não sustentam suspeita.
