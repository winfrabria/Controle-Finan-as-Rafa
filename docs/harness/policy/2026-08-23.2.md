# Política de auditoria 2026-08-23.2

- Terra high é o modelo principal; Sol high é a única recuperação distinta.
- A recuperação só ocorre após rejeição de configuração, timeout ou resposta
  estrutural inválida, com no máximo duas chamadas por etapa.
- OCR já devolvido em `file_annotations` é reutilizado no fallback.
- `OTHER` é uma categoria aceita e nunca bloqueia o envio.
- Documento legível sem base suficiente termina como
  `INFORMATION_INSUFFICIENT`; documento realmente ilegível termina como
  `READ_FAILED`; erro técnico termina como falha de processamento.
- Campo vazio só sustenta suspeita com obrigatoriedade explícita no documento ou
  política global verificada.
- Cobertura parcial ou desconhecida nunca autoriza `TOTAL_MISMATCH`.
- Nenhuma regra depende de fornecedor, nome de arquivo, número, placa ou valor
  de um caso real.
