# Política de auditoria 2026-08-21.1

Esta versão estabiliza a reconciliação e reduz falsos positivos e negativos
sem criar regras para fornecedores, arquivos, identificadores ou valores reais.

- `TOTAL_MISMATCH` exige cobertura completa e uma camada contabilizável;
- camada total explicitamente vazia é falha estrutural de leitura, nunca `OK`;
- pagamentos agregados são conciliados com todas as parcelas e documentos do
  mesmo grupo;
- divergência objetiva permanece achado; fato externo ausente permanece
  pergunta de contexto;
- categorias universais só registram ausência quando a cobertura dos itens é
  completa;
- gatilhos complexos elevam o esforço do avaliador para `xhigh`;
- segredos e credenciais genéricas são removidos antes da persistência.

O modelo de produção não foi alterado nesta versão.
