# Matriz de decisão 2026-08-23.2

Ordem de decisão:

1. documento realmente vazio, corrompido, protegido ou ilegível: `READ_FAILED`;
2. achado objetivo sustentado: `SUSPICIOUS`;
3. pergunta concreta sobre fato externo ausente: `NEEDS_CONTEXT`;
4. documento legível, porém sem base estrutural suficiente:
   `INFORMATION_INSUFFICIENT`;
5. cobertura suficiente sem achado sustentado: `OK`.

`OTHER` segue a mesma matriz. Cobertura parcial nunca autoriza divergência total
nem ausência categórica de um item.
