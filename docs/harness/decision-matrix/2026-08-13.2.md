# Matriz de decisão 2026-08-13.2

| Situação | Resultado |
| --- | --- |
| Ficha, recibo, venda e pagamento concordam | segue para demais regras |
| Valor interno diverge sem desconto explícito | `SUSPICIOUS` |
| Data interna diverge | `SUSPICIOUS` |
| Desconto explícito reconcilia a diferença | não cria achado |
| Recibo simples ou sem valor fiscal, sem outra divergência | não cria achado |
| Falta fato externo essencial | `NEEDS_CONTEXT`, no máximo três perguntas |
| Documento sem conteúdo mínimo confiável | `READ_FAILED` |

Os achados determinísticos são deduplicados com os achados livres antes da
classificação final.
