# Schema 2026-08-23.1

A extração de cada item passa a registrar `arithmeticVerified`.

- `true`: quantidade, preço unitário e total impresso foram confirmados
  visualmente na mesma linha de origem;
- `false`: ao menos um desses números está incerto, cortado, borrado ou foi
  inferido pela leitura;
- extrações anteriores sem o campo são tratadas de forma conservadora pelas
  regras aritméticas.

Não há migration: o campo permanece dentro de `Note.extractedData`.

Cada item também recebe `sourcePage` e `sourceText`, usados para levar o usuário
à página e ao menor trecho que sustenta o apontamento. Esses campos não fingem
um recorte visual: coordenadas de imagem continuam fora deste contrato.
