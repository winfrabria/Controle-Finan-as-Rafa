# Schema 2026-08-23.2

`requiredFieldChecks` passa a carregar a base da obrigatoriedade:

- `requirementBasis`: `EXPLICIT_DOCUMENT`, `VERIFIED_POLICY` ou `NONE`;
- `requirementEvidence`: texto curto que comprova a base;
- `boundingBox`: localização opcional em coordenadas normalizadas ou pixels.

Itens e observações de evidência também aceitam `boundingBox` opcional. Dados
antigos sem esses campos continuam válidos e são tratados de forma
conservadora.

A execução registra uma categoria interna segura de falha: provedor,
configuração, timeout, extração incompleta ou documento ilegível, além de modelo,
status HTTP, provedor, request ID e metadados de roteamento permitidos.
