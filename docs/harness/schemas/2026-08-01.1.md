# Schemas 2026-08-01.1

O resultado estruturado de auditoria contém `findings`, `coverage`, `summary`,
`needsContext` e até três `contextQuestions`. Perguntas usam `TEXT`, `NUMBER`,
`SINGLE_SELECT` ou `BOOLEAN`; opções são obrigatórias apenas para seleção.

O contrato interno aceita `NEEDS_CONTEXT` com zero perguntas para o resultado da
reanálise. Na primeira avaliação, o pipeline rejeita `needsContext=true` sem
pergunta persistível para impedir loop.

Respostas públicas usam `{ respostas: [{ perguntaId, valor }] }`. O contrato
público mapeia `BOOLEAN` para `CONFIRMATION` e `SINGLE_SELECT` para `SELECT`.
Respostas são normalizadas, limitadas a 500 caracteres/valor numérico/booleano,
validadas contra a rodada atual e armazenadas com fingerprint canônico.

O endpoint público nunca retorna achados, classificação, prompt, resposta
interna, custo, reasoning ou caminho original do arquivo. O REVIEWER recebe
somente o diagnóstico final; perguntas e respostas ficam disponíveis apenas
para ADMIN.
