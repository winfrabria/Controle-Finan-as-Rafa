# Schemas 2026-08-13.3

O contrato de `evidenceObservations` adiciona `documentGroup`, identificador
opcional e estável do comprovante, NF, boleto ou pagamento ao qual a observação
pertence. O campo permite conciliar um pagamento agregado com a soma dos itens
do mesmo documento, sem comparar o total pago com cada produto isoladamente.

Extrações antigas continuam válidas: o normalizador preenche `documentGroup=null`.
Não há migration de banco porque `Note.extractedData` permanece JSON versionado.

Cada item também pode informar `documentRole` e `documentGroup` para ligar uma
cobrança agregada aos seus documentos de suporte. O novo
`requiredFieldChecks` preserva campo, rótulo, obrigatoriedade explicitamente
declarada, preenchimento, página e evidência. Extrações antigas recebem lista
vazia e continuam reprocessáveis.
