# Schemas 2026-08-13.2

O contrato de extração foi ampliado sem migration de banco porque
`Note.extractedData` já é JSON versionado.

## Novos campos

- `documentKind`: `FISCAL_INVOICE`, `REIMBURSEMENT`, `COMPOSITE`,
  `PAYMENT_PROOF` ou `OTHER`;
- `items[].evidenceObservations[]`:
  - `kind`: `SHEET`, `RECEIPT`, `SALE`, `PAYMENT`, `DISCOUNT` ou `OTHER`;
  - `label`;
  - `amount`;
  - `date`;
  - `page`;
  - `text`.

O array tem limite de 12 observações por item. Cada observação precisa conter
ao menos valor, data ou trecho. Extrações antigas continuam válidas por defaults
seguros (`documentKind=OTHER` e lista vazia).
