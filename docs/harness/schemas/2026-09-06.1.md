# Schema 2026-09-06.1

Incremento do schema 2026-08-28.1, sem migration.

- Datas ISO precisam existir no calendário, incluindo a regra de ano bissexto.
- O parser de recuperação substitui datas inválidas por `null` e acrescenta
  uma limitação de leitura. Valores, itens, páginas e trechos são preservados.
- A recuperação atende payloads canônicos e aliases legados, não altera a
  entrada e é idempotente. A reanálise de dados persistidos usa o mesmo parser.
- O contrato dos casos dourados preserva `supportCoverage` opcional.
- `INFORMATION_INSUFFICIENT` continua no formato legado de persistência:
  `auditResult=NEEDS_CONTEXT`, `classification=NO_PARAMETER` e
  `processingStage=COMPLETED`; a interface mostra “Informação insuficiente”.
