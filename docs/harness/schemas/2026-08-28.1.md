# Schema 2026-08-28.1

Mudança aditiva no contrato estruturado do verificador:

- todo `AI_VERIFICATION` inclui `confirmsInitialFindingCode`, string ou null;
- vínculo não nulo só é válido quando encontra uma hipótese `AI_DISCOVERY` do
  mesmo código e do mesmo par de valores ou datas;
- a página do achado deve existir dentro de `expectedPageCount`;
- código, valores ou página divergentes invalidam a resposta para confirmação.

Não houve mudança Prisma nem migration nesta versão.
